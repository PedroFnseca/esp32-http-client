    Contato Suporte

    Contato¶

    Tem dúvidas, sugestões ou precisa de suporte? Você pode entrar em contato diretamente por e-mail ou utilizar o GitHub para problemas e discussões.

    E-mail Oficial de Suporte¶

    Para dúvidas diretas, questões técnicas ou oportunidades de colaboração:

    Suporte Direto

    E-mail: support@esp32httpclient.com

    Para que Usar este Canal¶

    Você pode entrar em contato para:

    • Dúvidas Gerais — Perguntas sobre recursos da biblioteca ou arquitetura.
    • Suporte Técnico — Ajuda para solucionar dúvidas de configuração e uso.
    • Feedbacks e Sugestões — Ideias para aprimorar a biblioteca ou documentação.
    • Oportunidades de Colaboração — Parcerias, patrocínios ou colaboração em código aberto.
    • Segurança e Assuntos Sensíveis — Notificação responsável de vulnerabilidades.

    GitHub Issues vs. Contato Direto¶

    Para manter as discussões organizadas, utilize o canal mais adequado:

    Assunto Canal Recomendado Detalhes
    Relato de Bugs GitHub Issues Para erros reproduzíveis e envio de logs.
    Sugestão de Recursos GitHub Issues Para propostas de novas funcionalidades.
    Perguntas da Comunidade GitHub Discussions Para dúvidas e troca de experiências com outros desenvolvedores.
    Contato Direto / Privado Suporte por E-mail Para suporte individual, parcerias ou assuntos privados.
