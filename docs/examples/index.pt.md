# Exemplos

Todos os exemplos estão disponíveis no diretório [`examples/`](https://github.com/PedroFnseca/esp32-http-client/tree/main/examples) e podem ser abertos diretamente do Arduino IDE em **Arquivo → Exemplos → ESP32-HTTP-Client**.

| Exemplo | Descrição |
| :--- | :--- |
| [GET Simples](simple-get.pt.md) | Busca básica de dados, vinculando múltiplos campos de uma resposta JSON. |
| [Requisição POST](post-request.pt.md) | Enviando um corpo JSON e lendo o ID do recurso criado. |
| [JSON Aninhado](nested-json.pt.md) | Extraindo campos profundamente aninhados usando caminhos com notação de ponto. |
| [JSON Array](array-json.pt.md) | Endereçando elementos específicos de um array JSON por índice. |
| [JSON Bruto](raw-json.pt.md) | Capturando objetos inteiros ou sub-arrays em uma `String` do Arduino. |
| [PUT & DELETE](put-delete.pt.md) | Atualizando e excluindo recursos remotos. |
| [Timestamp Unix](unix-timestamp.pt.md) | Buscando um timestamp Unix do tipo `long` de uma API de horário. |
| [Porta Personalizada](port-selection.pt.md) | Conectando a um servidor rodando em uma porta não padrão. |
