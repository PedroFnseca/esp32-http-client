# Contact

Have questions, suggestions, or need assistance? You can reach out directly via email or use GitHub for issues and discussions.

## What You Can Contact Us For

You are welcome to reach out regarding:

- :material-chat-question: **General Questions** — Inquiries about library capabilities or architectural advice.
- :material-lifebuoy: **Technical Support** — Help with troubleshooting setup and usage questions.
- :material-lightbulb-outline: **Feedback & Suggestions** — Ideas to improve the library or documentation.
- :material-handshake: **Collaboration Opportunities** — Partnerships, sponsorships, or open-source collaboration.
- :material-shield-lock-outline: **Security & Sensitive Reports** — Responsible disclosure of security vulnerabilities.

---

## GitHub Issues vs. Direct Contact

To keep discussions organized, please choose the best channel:

| Topic | Recommended Channel | Details |
| :--- | :--- | :--- |
| **Bug Reports** | [:material-bug: GitHub Issues](https://github.com/PedroFnseca/esp32-http-client/issues) | For reproducible errors and stack traces. |
| **Feature Requests** | [:material-star-outline: GitHub Issues](https://github.com/PedroFnseca/esp32-http-client/issues) | For new feature proposals and public roadmap discussion. |
| **Community Q&A** | [:material-forum-outline: GitHub Discussions](https://github.com/PedroFnseca/esp32-http-client/discussions) | For community questions and knowledge sharing. |
| **Direct / Private Inquiries** | [:material-email: Email Support](mailto:support@esp32httpclient.com) | For 1-on-1 questions, partnerships, or sensitive topics. |
